# resources/

Static inputs the ticketing code reads. Committed, small, edited by hand or rebuilt by a script.

| File | What | Status |
|---|---|---|
| `lexicon.json` | English and Filipino words for danger flags and category hints. Needs a native speaker's review | planned |
| `places.json` | About 700 schools, clinics, stations, malls and markets in Makati, for foot traffic (about 21 KB) | planned |
| `offices.json` | Which office handles which category | planned |

`places.json` comes from OpenStreetMap, so it is under the ODbL licence and the project must credit OpenStreetMap contributors.
